[bold]Everywhere[/bold]
  Tab             Next control
  Shift+Tab       Previous control
  Arrows          Move in a list
  j / k           Move down / up in a list
  Enter           Open or activate
  Esc             Back or close
  ?               This panel
  Ctrl+P          Command palette for this screen
  F5              Refresh (also Ctrl+R)
  J               Jobs and logs (Docker runs, TUI pool activity, serve log tail, container logs)
  q               Quit when no field is focused

[bold]Sessions[/bold]
  /               Search
  r               New run
  C               Recipes
  P               Personas
  d               Rules
  a               Analyze the selection
  s               Select (also Space)
  S               Select all
  R               Re-run the highlighted recipe as a new session
  f               Fork an ended session into a new multi-turn
  Ctrl+S          Save the row as a recipe
  E               Export a session bundle
  H               Show native Host sessions beside Eval
  n               Follow-up while awaiting
  e               Done while awaiting
  x               Delete (press twice)

[bold]Browser[/bold]
  [ ]  1-5        Timeline, Summary, Diff, Findings, Report
  Diff            Rewind snapshots (or approximate search_replace edits); Prompt/Assistant tabs above a files and hunk split; / fuzzy-finds path or hunk; h/l steps snapshots; y copies the highlighted file

  h / l / Left / Right    Previous / next turn on the Timeline
  j / k                   Previous / next event on the Timeline (also Up / Down)
  v               Timeline filter (Subagents lists spawn/finish; Background lists task and schedule bookends; Workflows lists workflow tool bookends)
  Summary         Session glance; Tasks, Workflows, Subagents, and Stats tabs (click the strip)
  Tail            Follow new events to the end while a turn is open (terminal and HUD). Off keeps the highlight still.
  Enter           Full-width event (Esc back to the list); or open a child from a spawn/finish row
  i               Jump to Findings
  f               Flag this event
  N               New note
  O               Edit or delete note
  n               Follow-up while awaiting
  e               Done while awaiting
  y               Copy the selection, the finding, or the focused / primary pane body
  Ctrl+Shift+C    Same as y
  Ctrl+C          Copy the selection or focused body; quit hint when neither applies
  mouse drag      Select text; release copies the selection (multi-line OK); y still works
  s               Open the share link when the session has one
  E               Export a session bundle
  x               Delete (press twice)

  Ctrl+Enter      Launch
  Ctrl+S          Save recipe
  T               Export this form as task YAML
  [ ]  1-3        Recipe, Runtime, Extras

[bold]Recipes[/bold]
  Enter           Open in the runner
  l               Launch
  s               Select
  n               New

  T               Export as task YAML

[bold]Personas[/bold]
  Enter           Edit
  n               New
  x               Delete
  Ctrl+S          Save in the editor

[bold]Pickers[/bold]
  s               Select
  Ctrl+S          Apply the selection
  Esc             Cancel

(awaiting) / N with this TUI. HUD panes are Tab and Ctrl+1-6; [ ] also
scope Timeline turns (all / next).

leader key, then one letter (leader+X). Esc or timeout cancels.
